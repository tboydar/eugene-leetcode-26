# 88. Merge Sorted Array（合併兩個有序陣列）— 簡單 ⭐

- **難度**：Easy（簡單）
- **連結**：https://leetcode.com/problems/merge-sorted-array/
- **日期標記**：2026-10-15（今日三題之一）
- **技巧**：雙指針（從尾端往前填）

## 題目敘述

給你兩個**非遞減排序**的整數陣列 `nums1` 與 `nums2`，以及兩個整數 `m`、`n`，分別代表兩陣列中「有意義元素」的數量。

請把 `nums2` 合併進 `nums1`，讓結果保持非遞減排序。
**不要回傳新陣列**，而是要**就地寫入 `nums1`**：

- `nums1` 的長度是 `m + n`，前 `m` 個是有效元素，後 `n` 個是 `0` 佔位。
- `nums2` 的長度是 `n`。

## 官方範例

**範例 1**

```
輸入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
輸出：[1,2,2,3,5,6]
```

**範例 2**

```
輸入：nums1 = [1], m = 1, nums2 = [], n = 0
輸出：[1]
```

**範例 3**

```
輸入：nums1 = [0], m = 0, nums2 = [1], n = 1
輸出：[1]
```

## 限制條件

- `nums1.length == m + n`
- `nums2.length == n`
- `0 <= m, n <= 200`
- `1 <= m + n <= 200`
- `-10^9 <= nums1[i], nums2[j] <= 10^9`

## 解題思路（一步步）

1. **三個指針**：
   - `p1 = m - 1`：指著 `nums1` 有效部分的最後一個元素
   - `p2 = n - 1`：指著 `nums2` 的最後一個元素
   - `p = m + n - 1`：指著 `nums1` 陣列最尾端（寫入位置）
2. **從尾端往前比**：當 `p1 >= 0` 且 `p2 >= 0` 時，把兩者較大的放到 `nums1[p]`，然後對應指針與 `p` 一起 `-1`。
3. **收尾**：如果 `nums2` 還有剩（表示 `nums1` 前半的較小元素都就位了），把剩下的 `nums2` 依序複製到 `nums1` 前面。
4. **完成**：`nums1` 就地成為合併後的完整陣列。

> 為什麼從尾端填？因為 `nums1` 的尾端是空的（`0` 佔位）。從尾巴往頭填，**永遠不會覆蓋到還沒比較過的 `nums1` 元素**，所以不需要額外陣列。

## 複雜度分析

- **時間**：`O(m + n)`（每個元素最多被處理一次）
- **空間**：`O(1)`（純就地，只用了三個指針）

## 參考程式碼

```python
# Python
class Solution:
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        p1, p2, p = m - 1, n - 1, m + n - 1     # 1. 三個指針
        while p2 >= 0:                           # 2&3. 從尾端比到 nums2 用完
            if p1 >= 0 and nums1[p1] > nums2[p2]:
                nums1[p] = nums1[p1]
                p1 -= 1
            else:
                nums1[p] = nums2[p2]
                p2 -= 1
            p -= 1
```

```javascript
// JavaScript
var merge = function (nums1, m, nums2, n) {
  let p1 = m - 1, p2 = n - 1, p = m + n - 1;   // 1. 三個指針
  while (p2 >= 0) {                             // 2&3. 從尾端比到 nums2 用完
    if (p1 >= 0 && nums1[p1] > nums2[p2]) {
      nums1[p] = nums1[p1];
      p1--;
    } else {
      nums1[p] = nums2[p2];
      p2--;
    }
    p--;
  }
};
```

## 3D 視覺化重點（three.js）

- `nums1` 下半段畫成**灰色排（佔位 0）**、`nums2` 畫成**另一排不同顏色**的立柱，數值 = 柱高。
- 雙指針做成「發光小光球」在柱子頂端移動；每次比較，較大的柱子會**複製飛到目標位置**，然後指針往左。
- 可以看到 `nums1` 的尾部空格被「由大到小」依序填滿——這正是「從尾端填」策略的直覺來源。
